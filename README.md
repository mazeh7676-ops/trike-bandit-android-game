# سه‌چرخه شوتی: دزد گوسفند (Tricycle Sheep Rustler 3D)

بازی سه‌بعدی هیجان‌انگیز، طنز و اکشن با سه‌چرخه کودکانه در روستا برای اندروید و وب.

---

## 🚀 نحوه آپلود در گیت‌هاب و بیلد خودکار فایل APK اندروید

این پروژه مجهز به **GitHub Actions CI/CD** اختصاصی است. با هر بار Push کردن پروژه به گیت‌هاب، فایل خروجی نصبی اندروید (`.apk`) به صورت خودکار بیلد شده و برای دانلود آماده می‌شود!

### گام ۱: ساخت ریپازیتوری در گیت‌هاب
۱. وارد سایت [GitHub.com](https://github.com) شوید و یک ریپازیتوری جدید (مثلاً `tricycle-rustler-game`) بسازید.

### گام ۲: ارسال کدها به گیت‌هاب
دستورات زیر را در پوشه پروژه اجرا کنید:

```bash
git init
git add .
git commit -m "Initial commit - Tricycle Sheep Rustler Android Game"
git branch -M main
git remote add origin https://github.com/نام_کاربری_شما/نام_ریپازیتوری.git
git push -u origin main
```

---

## 📲 دریافت فایل نصبی APK از گیت‌هاب

بلافاصله پس از push کردن:
1. در صفحه گیت‌هاب خود به تب **Actions** بروید.
2. گردش کار **Build Android APK** را می‌بینید که به طور خودکار شروع به بیلد پکیج اندروید می‌کند.
3. پس از اتمام (حدود ۲ تا ۳ دقیقه)، روی اجرای آن کلیک کنید.
4. در بخش **Artifacts**، فایل **`Tricycle-Sheep-Rustler-Android-APK`** را دانلود کنید.
5. فایل zip را باز کنید و فایل نصبی **`app-debug.apk`** را مستقیماً روی گوشی اندرویدی خود نصب و بازی کنید!

---

## 🎮 اجرای محلی (Local Development)

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه
npm run dev

# بیلد وب و سینک اندروید
npm run android:build
```
